# Joint-spatial-coherence-and-binary-annular-
This work investigates joint spatial-coherence and binary-annular pupil optimization for defocus-robust weak-amplitude imaging. A partially coherent Hopkins model is used to optimize the source coherence and phase-pupil geometry, achieving improved signed transfer and reduced contrast inversion across a prescribed defocus–frequency domain.


## IMPORTANT
All reported results are numerical simulations. No experimental measurements are included.

## MODEL BOUNDARIES
The numerical model is scalar, paraxial, weak-amplitude, and nominally monochromatic. It does not model high-NA vectorial effects, multiple scattering, sensor noise, full material dispersion, or laboratory imperfections. The manuscript reports these limits explicitly.
